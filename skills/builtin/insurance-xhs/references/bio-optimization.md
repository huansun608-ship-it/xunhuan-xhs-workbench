# 学员主页简介优化

适用于单个学员或批量陪跑中的小红书简介改写。目标是让访客看懂这个人是谁、能提供什么具体价值，以及为什么值得继续看或咨询，同时保留每个人的特点。

## 先读本人，再参考对标

- 保留现昵称、简介原文，结合近期笔记和置顶内容判断实际主线；记录来源、采集时间及材料缺口，沿用已有表格的来源字段即可。
- 分清本人自述、主页可见内容、教练提出的定位建议。自述可作为起草依据，但不能说成已独立核实；内容主题不能直接证明职业资质或服务能力。
- 当作业里选择的对标方向与本人持续发布的内容不一致时，先按本人实际情况起草，并说明待确认的方向。对标用于借鉴表达和结构，不能提供学员的学历、任职、城市、客户数或专长。
- 粉丝、获赞用于了解阶段，不直接决定简介定位。新账号不等于职业新人，旧账号的数据也不能直接当成新账号成绩。

## 逐人确定改法

先找出最值得保留的差异：真实职业转型、具体服务人群、内容专长、本人说话方式、与业务相关的生活身份。优先保留能被其内容或经历支持的两三项，避免把所有人的简介写成同一套话。

已有清晰定位的，做精简和顺序调整即可。内容与简介偏离的，说明两者差别，给出符合当前内容的版本或标明转向建议。暂无简介但内容充分的，按内容主线补写；简介与内容都不足的，交付基础草稿，把拟定人群和方向列为待确认，不补造专家身份。

客户咨询、职业招募、生活记录等目标并存时，确定本轮主要用途；目标尚不明确的，说明起草假设。不要默认所有账号都要强推咨询。

## 写成可读的主页文案

通常用3—4行，按实际需要组合下列信息，顺序可调整：

- 身份与记忆点：读者能记住的真实背景。
- 对象与问题：服务谁，或持续讨论什么具体问题。
- 内容与信任：读者能看到什么，辅以相关且有依据的经历或证明。
- 沟通与个人特点：自然的下一步，或适当保留生活感。

这是选材框架，不要求每人四项齐全。避免堆资质、罗列所有产品、只说“干货分享”“专业靠谱”，以及人人都用同一句“私信我”。简介已经清楚时，不为显得改动大而重写定位。

小红书版本可默认每行搭配一个与内容相关的表情，用户另有偏好时调整。表情用于分行和传达语气，不宣称能提升平台推荐。尽量短而具体，优先保证手机端易读；不把固定字数当成未经核实的平台上限，发布前再按实际输入框调整。

例如，已有程序员转型经历且持续讲核保的学员，可以突出“程序员转型＋结构化解释＋健康告知与核保要求科普”；不能仅因对标账号讲养老，就改成养老专家。生活型账号可以保留育儿、阅读等特点，再补与真实保险内容的连接。

## 事实与承诺的处理

- 不把“8年保险买家”改成“8年保险从业”；不把金融、银行或财务年限并入保险年限。没有明确先后时，不编造职业转型顺序。
- 客户人数、家庭数、案件数、实操次数和理赔金额分别保留口径。自购保单、客户服务与保险公司的赔付结果不混用。
- 同一人简介和笔记数字冲突时，先省略冲突数字并列出确认项，不擅自采用更大的值。需要时保留原自述，但明确核对统计周期与含义。
- 学医经历不等于医生执业；证书不等于保险公司审批权限。未明确披露的明亚任职、职级、学历、法律或医疗身份不补写。
- 去掉“理赔100%赔付”“保证赔”“最适合”“避开90%的坑”等无充分依据的保证或量化收益，改为具体服务行为，如条款解释、投保分析、理赔协助。
- 不承诺无法确认能持续兑现的更新频率、响应时限或服务结果。简介围绕保障需求、责任范围和服务能力，不加入理财主题或投资收益导向表述。

这些处理用于保险案例；其他行业按同样原则核对与其业务有关的资质、数字和承诺，不强加保险字段。

## 交付与陪跑复盘

批量表格默认保留原文，在末尾追加：

| 字段 | 写什么 |
| --- | --- |
| 优化简介V1（带表情） | 每人一版可读的完整草稿；基础版也应写完整 |
| 调整理由 | 保留了什么特点，依据哪些内容，为什么调整 |
| 待本人确认项 | 影响使用的身份、数字、方向或目标疑问；没有实质疑问则说明即可 |

用户已有列名或交付形式时沿用其要求。“确认后简介”只存本人已确认的版本，不自动用草稿填充。无需为每份草稿重复申请起草许可；标明待确认项即可继续完成已授权工作。修改账号主页、发布等外部操作需另有对应授权。

交付前检查每人是否都有版本、是否串人、是否套用同一文案、是否加入无来源事实，以及简介能否与置顶和近期内容对应。若改了定位，同时说明昵称、置顶或后续内容需要怎样配合，不能把修改简介本身当作转型已经完成。

陪跑时按本人反馈修改，再看主页访问后的关注、有效咨询及咨询人群是否更匹配；数据可用时记录观察周期和同期内容变化。不能只凭点赞、粉丝涨跌或短期波动判断简介效果，也不能预先保证提升幅度。
