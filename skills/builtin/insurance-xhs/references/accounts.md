# 原包对标账号候选与核验方法

这些名称来自用户提供的原始skill，尚未核验账号链接、身份和当前状态。原包没有数据采集日期、页面链接或咨询成交记录；不沿用其“实测跑通”、赞粉比证明精准、停更证明失败等结论。

原主文件的补充名称与此库不完全一致，不合并宣称为同一份已验证账号库。对标只研究保障需求相关内容；不因候选账号存在而纳入理财主题。

## 使用方法

1. 按用户目标选择相近的人群、问题类型和表达方式；不按性别强分“闺蜜型”，不把爸妈或专业背景套给作者。
2. 能访问时核实账号链接、查询日期与近期样本。名称相同不能证明同一账号。
3. 拆具体笔记：题目回答什么、开头如何进入、判断有什么依据、结尾如何承接。记录可观察事实，避免推测后台咨询和成交。
4. 借鉴问题切法和组织方式，不抄原文、个人身份、客户故事或效果数字。

## 建议记录字段

账号名与链接 / 查询日期 / 样本链接及日期 / 服务人群 / 主问题 / 标题与开头机制 / 判断及证据 / 结尾动作 / 可借鉴之处 / 不适用条件。

粉丝与互动如需记录，应注明采集时点与口径。累计赞藏/当前粉丝不是单篇互动率、咨询率或成交指标，不能由此认定内容精准、获客成功或账号失败。无法访问时只说明分析框架，不编当前数据。
