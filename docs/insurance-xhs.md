为保险经纪人或代理人提供个人账号定位、主页简介优化、选题、笔记与口播创作、内容初审、对标研究和数据复盘。完整入口见 [SKILL.md](../skills/builtin/insurance-xhs/SKILL.md)。

## 单独下载与安装

从 [insurance-xhs v1.4.2 发布页](https://github.com/huansun608-ship-it/xunhuan-xhs-workbench/releases/tag/insurance-xhs-v1.4.2) 下载 `insurance-xhs-v1.4.2.zip`。解压后得到 `insurance-xhs/`，内含 `SKILL.md` 与全部引用文件。

- Codex：将整个 `insurance-xhs` 文件夹放入用户的 `.codex/skills/` 目录。
- Claude Code：将整个文件夹放入 `.claude/skills/` 目录。
- 已有同名安装：先备份旧文件夹，再换成解压的新文件夹；重新加载技能后使用。

压缩包移除了工作台专用的 `layer` 字段，并在 `metadata.version` 中标明版本；正文和参考文件与仓库版本一致。工作台使用仓库内目录，无需安装该压缩包。
